# Google Drive Interactions

The scripts in this folder interact with a particular subfolder of the LTER Network Office's Shared Google Drive. That folder can be found at this path: `LTER-LNO-general > diversity > diversity-surveys > 2024 survey > 2024 survey Raw Data` .

**For the code in that folder to be run-able, you need to have:**

1. Access to the "2024 survey Raw Data/" folder
2. Authenicated with the `googledrive` R package

For help with the latter point, see this [handy tutorial](https://lter.github.io/scicomp/tutorial_googledrive-pkg.html), developed by the LTER Scientific Computing team!
